# Systems Analysis: Campus Equipment Checkout System

**Target roles:** Systems Analyst Intern, IT Analyst Intern, MIS Intern.

## Scenario
A **fictional** campus IT department loans laptops and chargers to students. The current spreadsheet-based workflow can cause duplicate assignments and unclear return dates. This analysis proposes a simple checkout system. No real institutional data was used.

## Deliverables
- `stakeholders-and-requirements.md`: Stakeholder needs, functional/non-functional requirements, scope.
- `use-cases.md`: Actors, main use cases, exception handling.
- `process-flow.mmd`: Mermaid workflow diagram.
- `erd.mmd`: Mermaid entity relationship diagram.
- `traceability.csv`: Requirements mapped to acceptance tests.
- `data-dictionary.md`: Entity definitions and business rules.

## Viewing diagrams
Paste `.mmd` file content into https://mermaid.live/ or use a Mermaid preview in a Markdown-aware editor. Export a PNG/SVG after you review the model.

## What you should do yourself
Interview a fictional stakeholder (or write a clearly labeled hypothetical interview), revise requirements, identify a trade-off, and explain how you validated the acceptance criteria.
